## 2024-05-24 - XML External Entity (XXE) Vulnerability in lxml Parser
**Vulnerability:** The `clean_xml_to_string` function in `src/utils/__init__.py` used `etree.fromstring` to parse raw XML from event logs without disabling external entity resolution, creating a Critical risk of XML External Entity (XXE) attacks. Malicious XML could expose local files, internal networks, or cause a denial of service.
**Learning:** Python's `lxml.etree` parser resolves external entities by default. When parsing untrusted XML data (like event logs from potentially compromised systems), this default behavior is dangerous. Furthermore, `lxml` expects byte strings; attempting to pass strings with an XML declaration (e.g., `<?xml version="1.0" encoding="UTF-8"?>`) to `fromstring` can result in a `ValueError`.
**Prevention:** Always parse XML using an explicit, secure parser configuration: `parser = etree.XMLParser(resolve_entities=False)`. Additionally, robustly handle the input type by ensuring strings are encoded to bytes (e.g., `xml_string.encode('utf-8') if isinstance(xml_string, str) else xml_string`) before passing to `etree.fromstring`.
